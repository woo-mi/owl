# Animation optimization

Live prototype: https://woo-mi.github.io/owl/animation-optimization/

Independent copy of https://woo-mi.github.io/owl/mvp-animated/, created
November 23, 2026. The original prototype is preserved.

The copy retains the original automatic conversation playback, reply animations,
workspace, Owl customization, and reduced-motion behavior. All assets and
interactions are local copies. Static HTML/CSS/JavaScript; no build step.
Serve this directory over HTTP.

The version selector includes **before** (this directory), **after 1**,
**after 2**, and **after 3**. After 2 duplicates before, and after 3 duplicates
after 2. Both were created November 24, 2026, with the original animation behavior.

This is an interaction prototype using sample content, without live AI, accounts,
analytics, file upload, or microphone services.
