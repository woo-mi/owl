# Owl

Prototype overview: https://woo-mi.github.io/owl/

This repository publishes its `main` branch root through GitHub Pages. No build
step is required.

- `index.html` and `owl-mark.svg` provide the overview page.
- `emoji/` is **emoji**, based on the Pen `1 default` screen.
  Published at https://woo-mi.github.io/owl/emoji/.
- `owl-affordance/` is **Owl affordance**, based on the Pen `Owl affordance new`
  frame (`wPX4D`). Its white “Meet your Owl” coach mark introduces Owls from the search home screen.
  “Got it” or Escape dismisses the coach mark; the highlighted rail icon
  opens the FTUX prototype. Published at https://woo-mi.github.io/owl/owl-affordance/.
- `owl-old/` is **Owl old**, a standalone snapshot of the overview and its local
  prototypes at commit `520b976`. Published at https://woo-mi.github.io/owl/owl-old/.
  Existing external prototype links keep their original destinations.
- `full-page-workspace-layout-including-goals/` is **Full-Page Workspace Layout Including Goals**, an independent copy of
  `for-dev/` at commit `e3504ba`. V1 opens the Pen **Workspace Page** layout from the owl profile,
  with a compact application rail, full-page workspace navigation, Goals, and the New goal flow.
  Published at https://woo-mi.github.io/owl/full-page-workspace-layout-including-goals/.
- `mvp-new/` contains the current **MVP NEW** prototype, published at
  https://woo-mi.github.io/owl/mvp-new/.
- `mvp-animated/` is the animated copy of For dev, published at
  https://woo-mi.github.io/owl/mvp-animated/. It opens Oct 28 V2.
  The former `mvp-next/` URL redirects to this prototype.
- The MVP, Prototyping 1, and Prototyping 2 links retain their existing destinations
  in `woo-mi/agent-home-versions`.

Make future MVP NEW and overview-page updates in this repository. The previous
MVP NEW address in `agent-home-versions` redirects to the new location, preserving
its view, reply-thread query parameters, and hash.
