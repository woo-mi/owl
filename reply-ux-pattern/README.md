# Reply UX Pattern

Live URL: https://woo-mi.github.io/owl/reply-ux-pattern/

The conversation matches the Pen frame **connecting line · one topic** (`omuzR`):
the outlined goals prompt and 5 Replies link, curved reply connector, Q4 updates,
Customer-growth trends and fixes, and Q4 audit. Section connectors and trend glyphs
are preserved. All conversation content appears immediately without animation.

New Chat restores the complete conversation. The composer, conversation index,
Connections dialog, workspace, and Owl customization remain available.
The prototype is a static design sample; no messages or account actions are sent.
