# Reply UX Pattern

Live URL: https://woo-mi.github.io/owl/reply-ux-pattern/

V1 matches the Pen frame **connecting line · one topic** (`omuzR`):
the outlined goals prompt and 5 Replies link, curved reply connector, Q4 updates,
Customer-growth trends and fixes, and Q4 audit. Section connectors and trend glyphs
are preserved. All conversation content appears immediately without animation.

New Chat restores the complete conversation. The composer, conversation index,
Connections dialog, workspace, and Owl customization remain available.
The prototype is a static design sample; no messages or account actions are sent.

The bottom-right V1–V4 picker stores the selected version in the URL. V2 matches
**connecting line · two topic** (`I0AYM4`), adding the revenue question, its
reaction, and the looped thread connector. V3 matches **constraints of connecting
line · more than three ongoing topics** (`bvO7d`), including the red Topic A–D labels,
red explanatory note, repeated prompts, and revenue analysis. V4 still uses V1.
Each version keeps its own messages, draft, and scroll position when switching.
