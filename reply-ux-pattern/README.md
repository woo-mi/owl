# Reply UX Pattern

Live URL: https://woo-mi.github.io/owl/reply-ux-pattern/

Independent copy of FTUX. The entire final conversation appears immediately,
including all seven connected tool states, the Yes reply and reaction, and the
Weekly Sales Pipeline Review app preview. No typing, connection simulation,
message entrances, or automatic scrolling runs on load.

New Chat restores the complete conversation. The composer, conversation index,
Connections dialog, app link, workspace, and Owl customization remain available.
No real account connection or app generation occurs in this prototype.
