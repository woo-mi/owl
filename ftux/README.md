# FTUX

Live URL: https://woo-mi.github.io/owl/ftux/

The prototype presents the “FTUX real” (KJKJh) screen using the same automatic
conversation animation as MVP with animation. Bubbles arrive about two seconds
apart with typing dots, a soft rise and settle, and a separate emoji reaction.
The existing blue Yes message, CRM section, and Weekly Sales Pipeline Review
app preview appear in sequence without requiring clicks to advance.

Initial connection states match the design: Notion and HubSpot are Connected,
Gmail reads Connecting..., and the remaining tools show Connect. These are static
prototype states. Clicking Connect updates that tool immediately without revealing
additional messages. New Chat restarts the reference conversation animation.
Opening the workspace finishes playback; returning preserves the conversation.
Scrolling back or choosing an index topic stops automatic scrolling. Reduced
motion shows the complete conversation immediately without entrance animation.

The conversation index, app link, workspace, and Owl customization remain available.
No real account connection or app generation occurs in this prototype.
