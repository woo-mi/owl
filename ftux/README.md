# FTUX

Live URL: https://woo-mi.github.io/owl/ftux/

The prototype displays the complete “FTUX real” (KJKJh) screen immediately.
There is no timed playback, typing indicator, staged reveal, or extra Yes prompt.
The existing blue Yes message, CRM section, and Weekly Sales Pipeline Review
app preview are included in the transcript from first load.

Initial connection states match the design: Notion and HubSpot are Connected,
Gmail reads Connecting..., and the remaining tools show Connect. These are static
prototype states. Clicking Connect updates that tool immediately without revealing
additional messages. New Chat restores the same complete reference screen.

The conversation index, app link, workspace, and Owl customization remain available.
No real account connection or app generation occurs in this prototype.
