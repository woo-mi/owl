# UI optimization

Static, responsive implementation of the Pen **third-party** screen (`TWj7d`).

Published at https://woo-mi.github.io/owl/ui-optimization/.

The Claude request card preserves the design content and desktop layout. The
sidebar is copied from the Links prototype, including its icons, ordering, recent
chats, and account avatar. At 900px and below it uses the same 48px compact rail;
on phones the request fields stack. The page grows and scrolls on shorter screens.

This is a visual prototype: approval controls are disabled, navigation is static,
and the composer is a non-editable preview. No JavaScript or interaction states
are added. Main-screen SVG artwork comes from the Pen frame; navigation artwork
and Inter are shared with the existing Reply UX Pattern prototype.
